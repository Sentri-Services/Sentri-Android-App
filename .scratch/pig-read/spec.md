## 已确认规则与实现取舍

- `mobile_webapp/src/pages/pigs/list/index.tsx` 按单元 location_code `_iregex` 查询；耳号或耳缺的 `includes` 区分大小写。原生分页利用旧 operation 的 offset/limit，稳定 ID 顺序来自旧 `db/pig.ts`。
- 新 Pig 查询只取本阶段读链路需要的字段，服务端 JWT 权限不变；显式 farm_id 约束及响应 farm_id 检查作为额外上下文约束。
- 新的只读缓存独立于旧 IndexedDB，SQLite 按 environment/oauth/user/farm/kind/参数键存储版本化快照；页面/详情最多保留 256 项/作用域，账户/位置元数据保留；更新/替换是事务，不删除其他作用域或旧 Web 存储。
- 请求、缓存与状态更新验证认证上下文 revision；刷新 Token 保留 revision，登录/退出/厂区变化递增。共享 GraphQL 执行器保持查询一次刷新重试、mutation 不重放。
- 账户上下文允许已选厂区的有效本地会话在网络失败时恢复，以支持离线重启；认证失效/权限拒绝不回退缓存。
- float8 使用 BigDecimal；JSON 保留数字字面量；时间戳保留服务器偏移和小数精度，本轮不计算年龄或时间差。
